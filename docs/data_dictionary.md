# Data Dictionary: Structural Analysis of Human DDX3X Protein

## 1. Primary Sequence and Annotation Files

### `data/DDX3X_human_O00571.fasta`
- **Format:** Standard FASTA sequence file
- **Source:** UniProtKB (`https://rest.uniprot.org/uniprotkb/O00571.fasta`)
- **Header:** `>sp|O00571|DDX3X_HUMAN ATP-dependent RNA helicase DDX3X OS=Homo sapiens OX=9606 GN=DDX3X PE=1 SV=1`
- **Length:** 662 amino acid residues
- **Fields:** Complete primary protein sequence (single-letter amino acid code).

### `data/DDX3X_human_O00571_uniprot.json`
- **Format:** JSON structure
- **Source:** UniProt REST API
- **Contents:** Functional descriptors, catalytic site coordinates, isoform data, subcellular localization annotations, and bibliographic references.

## 2. Structural Coordinate Files

### `data/AF-O00571-F1-model_v6.pdb`
- **Format:** Protein Data Bank (PDB) format
- **Source:** AlphaFold Protein Structure Database (EBI)
- **Model ID:** AF-O00571-F1 (v6)
- **Coverage:** Full-length human DDX3X (Residues 1–662, 5,188 total atoms)
- **Key Fields:** 
  - Standard atomic coordinates (Columns 31–54: X, Y, Z in Angstroms).
  - B-factor column (Columns 61–66): Contains AlphaFold per-residue prediction confidence score (pLDDT, 0–100 scale).

### `data/2I4I.pdb`
- **Format:** Protein Data Bank (PDB) format
- **Source:** RCSB Protein Data Bank
- **Title:** Crystal structure of the DEAD-box RNA helicase DDX3X core
- **Resolution:** 2.20 Å
- **Coverage:** Chain A covers residues 132 to 607 (helicase catalytic core in open apo conformation).

### `data/5E7I.pdb`
- **Format:** Protein Data Bank (PDB) format
- **Source:** RCSB Protein Data Bank
- **Title:** Crystal structure of human DDX3X in complex with AMP-PNP, magnesium, and ssRNA
- **Resolution:** 2.80 Å
- **Coverage:** Chain A covers residues 168 to 582 (catalytic core in closed substrate-bound state).

## 3. Processed Datasets

### `data/processed/ddx3x_structural_summary.json`
Generated by `scripts/02_analyze_structure.py`.
- **`sequence_metadata`:** Gene symbol, organism, accession, total length.
- **`structural_coverage`:** Number of residues resolved across AlphaFold and experimental crystal structures, mean pLDDT score.
- **`domains`:** Coordinate intervals for N-terminal tail, RecA-like Domain 1, Linker, RecA-like Domain 2, and C-terminal tail.
- **`motifs`:** Coordinate intervals, amino acid sequences, and biochemical functions for conserved helicase motifs (Q, I, Ia, Ib, II, III, IV, V, VI).
- **`per_residue_af`:** Dictionary keyed by residue number containing residue three-letter code and AlphaFold pLDDT score.
